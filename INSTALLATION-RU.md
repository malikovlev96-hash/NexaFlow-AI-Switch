# 📦 Установка NexaFlow AI Switch (Windows)

Это руководство относится к архиву `NexaFlow-Desktop-Mobile-1.0.0.zip`.

## 1. Скачать и распаковать

1. Открой [репозиторий NexaFlow](https://github.com/malikovlev96-hash/NexaFlow-AI-Switch).
2. Нажми на файл `NexaFlow-Desktop-Mobile-1.0.0.zip` и скачай его.
3. В Проводнике Windows нажми правой кнопкой по ZIP → **Извлечь всё…**.
4. Открой извлечённую папку `nexaflow_bundle`.

Внутри должны находиться:

- `START-NEXAFLOW.cmd` — главное меню запуска;
- `NexaFlow-AI-Switch-Pro-1.6.0.mcpb` — пакет расширения Claude Desktop;
- `mobile/` — файлы мобильного веб-приложения;
- `assets/` — значок и ресурсы.

**Важно:** не перемещай CMD-файл отдельно от MCPB, `mobile` и `assets`.

## 2. Запустить веб-приложение на компьютере

1. Установи Python 3 для Windows, если он ещё не установлен: [python.org/downloads](https://www.python.org/downloads/).
2. Запусти `START-NEXAFLOW.cmd` двойным щелчком.
3. В меню введи `1` и нажми Enter.
4. Должна открыться страница `http://127.0.0.1:8765/` в браузере.

Оставь папку на месте, пока пользуешься приложением. Локальный сервер работает на этом компьютере.

## 3. Установить расширение Claude Desktop

1. Установи и открой Claude Desktop.
2. В папке `nexaflow_bundle` запусти `START-NEXAFLOW.cmd`.
3. Выбери пункт `2` — откроется файл `NexaFlow-AI-Switch-Pro-1.6.0.mcpb`.
4. Подтверди установку в окне Claude Desktop, если появится запрос.
5. После установки проверь расширение в настройках Claude Desktop и заполни его конфигурацию API-ключом провайдера.

Если двойной щелчок по `.mcpb` не открывает установщик, используй доступный в твоей версии Claude Desktop экран установки расширений и выбери этот `.mcpb` вручную. Названия пунктов интерфейса могут отличаться между версиями.

## 4. Установить на Android или iPhone

Мобильная версия в этом архиве — PWA, а не APK/IPA. Её нельзя установить как обычный Android APK или приложение из App Store.

Для публикации:

1. Размести содержимое `nexaflow_bundle` на HTTPS-статическом хостинге.
2. Сохрани относительные пути `mobile/` и `assets/`.
3. Открой опубликованный адрес мобильной страницы на телефоне.
4. На Android в Chrome выбери меню → **Установить приложение** / **Добавить на главный экран**.
5. На iPhone в Safari нажми **Поделиться** → **На экран «Домой»**.

## 5. Безопасность ключей

- Не отправляй API-ключи другим людям и не публикуй их в GitHub.
- Мобильная PWA хранит ключ OpenRouter в локальном хранилище браузера (`localStorage`). Используй её только на доверенном личном устройстве.
- Мобильная PWA не синхронизирует ключи с Claude Desktop.
- Стоимость и лимиты запросов определяет провайдер и выбранная модель.

## 6. Частые ошибки

| Ошибка | Что проверить |
|---|---|
| `Python not found` | Установи Python 3 и включи добавление Python в PATH. |
| `127.0.0.1:8765` недоступен | Проверь, что Launcher запущен и локальный сервер не был закрыт. |
| `401 Unauthorized` | Проверь ключ, провайдера, доступ API и формат авторизации. |
| `Model not found` | Проверь точный ID модели в документации провайдера. |

Никогда не присылай API-ключ в сообщениях об ошибке. Замени его на `[REDACTED]`.
