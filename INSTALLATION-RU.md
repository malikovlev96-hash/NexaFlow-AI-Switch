# Установка NexaFlow AI Switch на Windows

Это руководство для актуальной структуры репозитория. Скачивай файлы из раздела [Releases](https://github.com/malikovlev96-hash/NexaFlow-AI-Switch/releases/latest), а не старый архив 1.0.0 из истории проекта.

## Что скачать

На странице последнего релиза (если он опубликован) скачай:

- `NexaFlow-AI-Switch-1.7.1-source.zip` — папка программы, Launcher, PWA и инструкции.
- `NexaFlow-AI-Switch-1.7.1.mcpb` — расширение для Claude Desktop.

Если релиза пока нет, открой главную страницу GitHub → **Code → Download ZIP**. MCPB можно собрать из исходников через `BUILD-MCPB.cmd`.

## 1. Распакуй программу

1. Найди скачанный ZIP в папке «Загрузки».
2. Нажми правой кнопкой мыши → **Извлечь всё…**.
3. Открой извлечённую папку.
4. Не перемещай отдельно `START-NEXAFLOW.cmd`, `desktop/`, `mobile/`, `assets/` и `server/` — они должны оставаться вместе.

## 2. Запусти веб-приложение на компьютере

1. Установи Python 3: [python.org/downloads](https://www.python.org/downloads/). Во время установки включи **Add Python to PATH**, если установщик предлагает этот пункт.
2. Дважды нажми `START-NEXAFLOW.cmd`.
3. В появившемся меню введи `1` и нажми Enter.
4. Дождись проверки сервера. Браузер откроет `http://127.0.0.1:8765/`.
5. Чтобы остановить сервер, снова запусти Launcher и выбери `2`.

Если окно сообщает об ошибке, выбери `4` — проверка покажет состояние Python и порта 8765.

## 3. Установи MCP-расширение в Claude Desktop

**Вариант A — готовый пакет из Releases**

1. Скачай `NexaFlow-AI-Switch-1.7.1.mcpb`.
2. Если Windows не открывает его двойным щелчком, запусти Claude Desktop и используй доступный в твоей версии экран установки расширений.
3. Выбери скачанный файл `.mcpb` и подтверди установку.
4. Открой настройки расширения и добавь API-ключ хотя бы одного провайдера.
5. Перезапусти Claude Desktop, если он попросит.

**Вариант B — собрать пакет самостоятельно**

1. Убедись, что установлен Python 3.
2. В папке проекта дважды нажми `BUILD-MCPB.cmd`.
3. После успешной проверки пакет появится в `dist/NexaFlow-AI-Switch-1.7.1.mcpb`.
4. Открой этот файл через Claude Desktop и подтверди установку.

## 4. Добавь API-ключ

NexaFlow не выдаёт API-ключи и не включает платный доступ к моделям. Получи ключ на сайте выбранного провайдера и вставь его в соответствующее чувствительное поле настроек расширения Claude Desktop.

Начни с одного провайдера. Проверь подключение через `autoswitch_test_provider`. Доступность моделей, бесплатные квоты и цены зависят от провайдера, аккаунта и региона.

Официальные ссылки: [настройка провайдеров](docs/PROVIDERS-RU.md).

## 5. Установи PWA на телефон

Мобильная версия — это сайт, который можно добавить на главный экран. Это **не APK и не IPA**.

1. Сначала размести корневую папку проекта на HTTPS-хостинге, сохранив папки `mobile/` и `assets/`.
2. Открой адрес сайта с окончанием `/mobile/`.
3. **Android:** Chrome → меню ⋮ → «Установить приложение» или «Добавить на главный экран».
4. **iPhone:** Safari → «Поделиться» → «На экран Домой».

PWA использует OpenRouter. Она не подключается к MCP-процессу Claude Desktop и не синхронизирует с ним ключи или историю.

## Безопасность

- Не публикуй API-ключи в GitHub, скриншотах и сообщениях об ошибках.
- Не используй PWA на чужих или общедоступных устройствах.
- PWA хранит ключ в `sessionStorage` текущей сессии браузера; история и избранное остаются в локальном хранилище браузера.
- Провайдер может взимать плату за запросы. Проверяй баланс и лимиты самостоятельно.

## Частые проблемы

| Проблема | Что сделать |
|---|---|
| Python не найден | Установи Python 3 и включи добавление в PATH. |
| Страница 127.0.0.1 не открывается | Запусти Launcher → пункт 4; проверь, что порт 8765 свободен. |
| Ошибка 401 | Проверь API-ключ и выбранного провайдера. |
| Ошибка 403 | Проверь права ключа, тариф, регион и доступ к модели. |
| Ошибка 404 / Model not found | Проверь точный ID модели в кабинете провайдера. |
| Ошибка 429 | Превышен лимит или квота; проверь тариф и попробуй позже. |
| MCPB не открывается | Открой Claude Desktop и установи пакет через доступный экран расширений. |

Если просишь о помощи, укажи версию NexaFlow, Windows/Claude Desktop version и текст ошибки. Все секреты замени на `[REDACTED]`.
