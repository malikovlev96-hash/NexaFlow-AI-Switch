Один проект.
Два сценария.

Выбери интерфейс под своё устройство. Это отдельные клиенты с разными возможностями.

DESKTOP · MCPB

Claude Desktop Extension

Подключение NexaFlow как MCP-расширения Claude Desktop. Установка через пакет .mcpb и работа с доступными инструментами.

Скачать для Claude Desktop ↗
MOBILE · PWA

Mobile Companion

Отдельный мобильный интерфейс: каталог OpenRouter, чат с потоковыми ответами, избранное и локальная история.

Открыть мобильное приложение ↗
Важно: мобильный companion работает отдельно, использует OpenRouter и не синхронизирует API-ключи или историю с Claude Desktop.
