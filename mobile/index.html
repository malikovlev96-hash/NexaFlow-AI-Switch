05 / Установка на телефон

Android: откройте HTTPS-сайт в Chrome → меню ⋮ → «Установить приложение». iPhone: откройте HTTPS-сайт в Safari → «Поделиться» → «На экран Домой». Для PWA нужен HTTPS (или localhost).

Важно: мобильная версия сейчас использует только OpenRouter. Она не синхронизирует ключи с Claude Desktop и не подключается к локальному MCP-процессу.
